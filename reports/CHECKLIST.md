# 지표 해부 체크리스트 (보고서 에이전트 교본)

이 문서는 발표일마다 자동 실행되는 보고서 에이전트의 작업 지침이다.
**데이터는 저장소 안의 `reports/data/<시리즈ID>.csv`에서 읽는다** (형식: `date,value` 한 줄씩, 날짜 오름차순).
GitHub Actions(fred-mirror, 평일 23:05 KST)가 FRED 공식 API로 미러링해둔 것 — 에이전트는 외부 네트워크가 필요 없다.
미러 시각은 `reports/data/_mirror_time.txt`. 데이터가 하루 이상 낡았으면 보고서에 그 사실을 명시하라.
보고서는 `reports/YYYY-MM-DD_지표.md`로 저장하고 `reports/index.json`에 `{file, date, title, tag}` 추가 후 커밋.

## 공통 원칙

- **항목별 전수 해부가 기본 골조다** (사용자 지정 2026-08-13): 모든 보고서는 아래 지표별 항목 테이블의
  전 항목에 대해 YoY·3개월 연율화를 계산하고, 가속/감속으로 갈라 "지금 어디서 무슨 일이 벌어지는지"를
  각 항목의 일반 속성과 함께 설명한다. 총지수 몇 개만 자르고 끝내는 보고서는 불합격.
- **함의·대조 섹션은 "그래서 하고 싶은 말"을 첫 문장으로 굵게 쓰고, 그 뒤에 근거를 풀어쓴다.** 결론만 압축해 던지지 마라.
  전문용어(PCE 예고편, PPI−CPI 갭, 슈퍼코어, 기저효과 등)는 **그 자리에서 한 줄로 정의**하고 쓴다 — 독자는 트레이더지 통계학자가 아니다.
  경로가 여러 개면 표로 "뜻 / 누가 아픈가 / 어디서 확인하나"를 나란히. (사용자 피드백 2026-08-17: "개떡같이 썼다")
- 헤드라인 숫자는 마지막에. **세부 구성 → 수정치 → 판정짝 → 헤드라인** 순서로 쓴다.
- 단월 숫자로 단정하지 않는다 — 3개월 흐름과 시그마 위치를 항상 병기.
- 이전 보고서와 판정이 달라지면 "무엇이 바뀌었나"를 첫 줄에.
- 지도(사이트)의 현재 국면 판독과 모순되면 명시하고, 지도 요약 갱신을 제안.

## PPI (CPI 다음 날께)

PPI는 **생산 파이프라인**이다. 원자재 → 중간재(4단계) → 최종수요 순으로 물가가 흘러내리므로,
보고서는 반드시 **3층(최종수요 / 중간수요 / 원자재)을 전부** 해부한다. 한 층만 보면 "어디서 오는 압력인지"를 못 읽는다.

1. 헤드라인·코어: PPIFIS, WPSFD4131(식품·에너지 제외), 슈퍼코어 WPSFD49116(식품·에너지·무역서비스 제외 — ⚠ 서비스 아님)

2. **1층 · 최종수요 항목별** (전부 2026-08-16 실물 검증):

| 항목 | 시리즈 | 일반적 속성 · 읽는 법 |
|---|---|---|
| 개인소비 (전체) | WPSFD49501 | PPI 안의 "소비자 바구니" — CPI와 가장 직결 |
| 개인소비 재화 | WPSFD49502 | CPI 상품의 상류, 1~3개월 선행 |
| 완성재 (재화 전체) | WPSFD49207 | 헤드라인 재화 |
| 완성재 식품 제외 | WPSFD49209 | 식품 파동 걸러낸 재화 |
| 완성재 에너지 제외 | WPSFD49208 | **관세 전가는 여기서 먼저** — 핵심 감시 |
| 완성 소비자 식품 | WPSFD4111 | CPI 가정식의 상류, 농산물 조기경보 |
| 완성 소비자 에너지 | WPSFD4121 | 유가·정제마진 반영, 변동 최대 |
| 완성 서비스 (무역 제외) | WPSFD49213 | 서비스 원가 압력 — 운송·창고·전문서비스 |
| 완성 서비스 (유통 제외) | WPSFD49214 | 무역 마진까지 뺀 순수 서비스 |
| 총 완성 에너지 제외 | WPSFD49206 | 재화+서비스 기조 |

3. **2층 · 중간수요 (생산 흐름 4단계)** — 상류일수록 선행. 4단계→1단계 순으로 최종수요에 도달:

| 단계 | 시리즈 | 읽는 법 |
|---|---|---|
| Stage 4 (최종수요 직전) | WPSID54 | 최종수요 1~2개월 선행 |
| Stage 3 | WPSID53 | 중류 |
| Stage 2 | WPSID52 | 상류 — 원자재 가공 초입 |
| 가공재 (중간수요) | WPSID61 | 전통적 "중간재 PPI" — 제조업 원가 |
| 미가공재 (중간수요) | WPSID62 | 원자재에 가장 가까움, 변동 최대 |
| 서비스 (중간수요) | WPSID63 | 기업 간 서비스 원가 |
| 건설 (중간수요) | WPSID64 | 건설 자재·공사비 — 주택 사슬과 연결 |

4. **3층 · 원자재/상품 항목** — 관세·지정학·기후 충격의 최전선:

| 상품 | 시리즈 | 읽는 법 |

5. **PCE 예고편**: PPI 중 PCE 산입 항목(의료·항공·포트폴리오 수수료) 방향으로 2주 뒤 PCE 물가를 선제 추정
6. 상류→하류 전이: PPI YoY − CPI YoY 갭 추세 (양수 확대 = 마진 압박 → 전가 대기). 원자재→중간→최종 각 층의 3개월 연율을 나란히 놓아 **압력이 어느 층에 있는지** 판정.

주간 지표라 월간 보고서와 형식이 다르다: **계기판 표 + 판정 3~4문단으로 압축.** 항목 나열보다 판정선 대비 위치가 핵심.
1. 신규 ICSA — **4주 평균으로만 판정** (단주 금지, 명절 주간 왜곡 주의). 판정선: 4주 평균 230K 돌파 = 해고 사이클 개시 경보
2. 연속 CCSA (신규보다 1주 지연) — 판정선 1,900K 재돌파
3. **연속÷신규 비율** — 재취업 난이도. 정상기 ~7.7, 9.5 지속 돌파 = 실업 장기화 고착. "해고 없는 위축" 국면의 핵심 계기판
4. **연속 청구 하락의 함정 명시**: 실업급여는 26주 소진 — 장기실업자는 청구 통계에서 사라진다. 연속 하락 ≠ 재취업. 가계조사 취업자·장기실업(UEMP27OV)과 대조
5. 흐름은 최근 6~8주 나열, 1년 전 같은 주와 비교
