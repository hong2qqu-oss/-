# 지표 해부 체크리스트 (보고서 에이전트 교본)

이 문서는 발표일마다 자동 실행되는 보고서 에이전트의 작업 지침이다.
**데이터는 저장소 안의 `reports/data/<시리즈ID>.csv`에서 읽는다** (형식: `date,value` 한 줄씩, 날짜 오름차순).
GitHub Actions(fred-mirror, 평일 23:05 KST)가 FRED 공식 API로 미러링해둔 것 — 에이전트는 외부 네트워크가 필요 없다.
미러 시각은 `reports/data/_mirror_time.txt`. 데이터가 하루 이상 낡았으면 보고서에 그 사실을 명시하라.
보고서는 `reports/YYYY-MM-DD_지표.md`로 저장하고 `reports/index.json`에 `{file, date, title, tag}` 추가 후 커밋.

## 공통 원칙

- **항목별 전수 해부가 기본 골조다** (사용자 지정 2026-08-13): 모든 보고서는 아래 지표별 항목 테이블의
  전 항목에 대해 YoY·3개월 연율화를 계산하고, 가속/감속으로 갈라 "지금 어디서 무슨 일이 벌어지는지"를
  각 항목의 일반 속성과 함께 설명한다. 총지수 몇 개만 자르고 끝내는 보고서는 불합격.
- 헤드라인 숫자는 마지막에. **세부 구성 → 수정치 → 판정짝 → 헤드라인** 순서로 쓴다.
- 단월 숫자로 단정하지 않는다 — 3개월 흐름과 시그마 위치를 항상 병기.
- 이전 보고서와 판정이 달라지면 "무엇이 바뀌었나"를 첫 줄에.
- 지도(사이트)의 현재 국면 판독과 모순되면 명시하고, 지도 요약 갱신을 제안.

## NFP — 고용보고서 (매월 첫 금요일)

4. **민간/정부 분해**: USPRIV / USGOVT (연방 CES9091000001)
5. **질**: 주당시간 AWHAETP · 임시직 TEMPHELPS · 경제적 파트타임 LNS12032194 · U6RATE
6. 산업별: USGOOD SRVPRD MANEMP USCONS USEHS USLAH USPBS USTRADE USINFO USFIRE USTPU
7. 원천징수 4주합(재무부 DTS)과 대조 — 단, 예측력은 국면 온도계 수준임을 명시 (백테스트 r=0.26)

## CPI (매월 중순)

1. **3개월 연율화 vs YoY** — 기저효과 걸러내기 (CPIAUCSL, CPILFESL)
2. **주거의 지연**: 주택 CUSR0000SAH1 · 임차료 CUSR0000SEHA · OER CUSR0000SEHC — 12~18개월 지연 명시
3. **제외 주거**: CUSR0000SA0L2 — 주거 빼면 인플레가 어디 있나
4. **코어 상품 vs 코어 서비스**: CUSR0000SACL1E vs CUSR0000SASLE — 관세(상품) vs 임금(서비스) 채널 분리
5. 판정짝: 트림드민 PCE(PCETRIM12M159SFRBDAL), 시장 기대 BEI(T10YIE)와 대조
6. **항목별 스캔** — 3개월 연율화 기준으로 가속/감속 항목을 갈라 "인플레가 지금 어디 사는지" 표로.
   채널별 묶음: 관세(의류·신차) / 임금(외식·의료서비스) / 유가(휘발유·항공) / 후행 꼬리(전기·교통서비스) / 지연(주거)
